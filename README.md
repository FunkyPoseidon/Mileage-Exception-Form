# Mileage-Exception-Form
This tool was created for use in the Texas Dallas East Mission (TDEM)

This tool can be used with Google Apps Script and is intended for use with a Google form.

It uses the contact sync feature to sync all the area information found in the Mission's Google Contacts. It automatically syncs this information with the area selector found in the Google form.

Missionaries then upload their mileage exceptions to the Google form. This information is automatically sorted into sheets based on the month and an overall summary page is generated with info for each area and how many miles they used.
